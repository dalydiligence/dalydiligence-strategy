# Daly Diligence Strategy

This repository documents the evolution of Daly Diligence LLC's strategy.

## Artifacts

- **Journal.docx** — A chronological record of how ideas, decisions, and strategy evolved. The journal has no required format. It is intended to be written by humans for humans.
- **Strategy.md** — The current strategy derived from the journal.

## Discussion

GitHub Issues are used to identify problems, propose ideas, and invite criticism.

GitHub Pull Requests are used to propose changes to repository artifacts.

## Guiding Principle

**Earn trust**
